Dungeon Hub Help

Features

The Dungeon Hub Bot offers a wide range of useful features to help you manage your Discord server. However, because there are so many features, some of them might be a little confusing for new users.
The following pages will cover the basics of the bot's features and explain how to use them. For more detailed explanations, you can refer to the linked topics on each feature's page.

  • Carry and Score System explains carry configuration, ticket logging, score, leaderboards, and purges.

  • Crafts, Transfers, and Reputation covers CNT requests, claiming, completion, and reputation.

  • Embed Management ✏️ documents the JSON format used to create and edit Discord embeds.

  • Player Profiles explains player data, profile selection, and Hypixel status information.

  • Player Lookup and Safety covers safety checks for Minecraft players and Discord users.

  • Role Management explains automatic roles, requirements, groups, and synchronization.

  • Server Property lists server-wide bot configuration.

  • Static Messages covers persistent bot-managed embeds.

  • Ticket System ✏️ explains ticket panels and the ticket lifecycle.

  • Verification ✏️ covers account linking and synchronization.

  • Warnings explains moderation records and automated punishments.
