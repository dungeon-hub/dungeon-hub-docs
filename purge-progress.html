/purge progress

Description

Shows the number of affected users and queued role-removal actions. The response indicates whether the wave is waiting to start or currently active. An error is returned when no purge is queued.

Arguments

This command takes no arguments.

Examples

/purge progress

See Also

  • /purge start

  • /purge clear
