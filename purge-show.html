/purge show

Description

Calculates and displays members who hold roles associated with the selected purge type and have default score below the threshold. This command does not queue or remove any roles. It warns if the carry type still has logs awaiting approval.

Arguments

Name

Type

Description

Optional?

Additional

carry-type

String

Carry-type identifier.

❌ No

Max length: 30; autocomplete available.

purge-type

String

Purge-type identifier.

❌ No

Max length: 30; autocomplete available.

threshold

Integer

Members with less default score are included.

❌ No

Min: 0; max: 100.

Examples

/purge show carry-type: dungeons purge-type: inactive threshold: 20
