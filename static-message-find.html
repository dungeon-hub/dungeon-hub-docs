/static-message find

Description

Displays static-message records in a paginator. Each record includes its ID, message link, type, assigned object IDs, and any embed override. Filter by a text channel or omit the argument to list messages from the entire server.

Arguments

Name

Type

Description

Optional?

Additional

channel

Channel

Only list messages registered in this channel.

✅ Yes

Text channels only.

Examples

/static-message find channel: #announcements
