/ticket claim

Description

Claims an open, unclaimed ticket. If the ticket is already claimed, the same command unclaims it. Claiming updates the ticket's permissions and configured channel name and notifies the ticket creator.

The ticket panel must have claiming enabled. Support or additional roles, members with Manage Channels, and administrators can claim. Only the current claimer, a member with Manage Channels, or an administrator can unclaim.

Arguments

This command takes no arguments and must be used in an open ticket channel.

Examples

/ticket claim
