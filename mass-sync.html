/mass-sync

Description

This command allows you to queue many users for role/nickname syncing. This queue is server-based, where one user is synced every 15 seconds to avoid Discord rate limits.

Common use cases for mass-sync include:

  • After adding or modifying role requirements, to apply the new rules to all members

  • To update outdated stats (Catacombs level, SkyBlock level, etc.) in nicknames and roles when users have progressed in-game but haven't manually run /sync

  • After updating guild membership on Hypixel, to sync guild-based roles

  • To refresh all nicknames and roles after configuration changes

Users must have a linked Minecraft account for syncing to apply game-based roles and requirements. Unlinked users will only have their basic Discord roles updated.

Sub-Commands

  • /mass-sync role ✏️: Add members of a role (or @everyone) to the sync queue.

  • /mass-sync guild ✏️: Add members of a Hypixel guild to the sync queue.

  • /mass-sync list: Show number of users currently queued.

  • /mass-sync clear: Clear the current queue.

See Also

  • /force-sync ✏️: single-user alternative.

  • /link: make sure users are linked before syncing.

  • Verification ✏️: the verification feature is described closer here.
