Dungeon Hub Help

/ticket

Description

The /ticket command provides subcommands for managing ticket channels. These commands allow support staff and ticket creators to close tickets, add users, and perform other ticket-related actions. All ticket commands must be used within a ticket channel and are subject to permission checks based on the ticket panel configuration.

For a complete overview of the ticket system, see Ticket System.

Sub-Commands

  • /ticket close: Close the current ticket channel (if the panel isn't closeable, the ticket will be deleted instead).

  • /ticket add: Add a user to the current ticket channel (support staff only).

  • /ticket claim: Claim an open ticket, or unclaim the ticket you currently own.

Delete, reopen, and transcript actions are available through button interactions within ticket channels.
