Dungeon Hub Help

/set-primary-profile

Description

Sets the primary SkyBlock profile on your linked Dungeon Hub account. The bot accepts either the profile's cute name or UUID and uses the selection when displaying stats across supported features. You must be linked first.

Arguments

Name

Type

Description

Optional?

Additional

profile

String

SkyBlock profile cute name or UUID.

❌ No

Autocompleted from your profiles.

Examples

/set-primary-profile profile: Apple
