/purge

Description

A purge removes the roles associated with a configured purge type from members whose default score for a carry type is below a selected threshold. Members with the configured PURGE_IMMUNITY_ROLE are excluded.

Review the candidates with /purge show before adding and starting a purge. Starting processes the queued role removals and cannot be stopped with /purge clear.

Workflow

  • /purge show previews affected members.

  • /purge add adds their role removals to the current purge wave.

  • /purge progress reviews the queued or active wave.

  • /purge start starts processing it.

  • /purge clear discards a wave that has not started.
