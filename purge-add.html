/purge add

Description

Calculates the same candidate set as /purge show and queues the configured role removals. It refuses to add candidates while the selected carry type has logs awaiting approval. No roles are removed until /purge start is used.

Arguments

Name

Type

Description

Optional?

Additional

carry-type

String

Carry-type identifier.

❌ No

Max length: 30; autocomplete available.

purge-type

String

Purge-type identifier.

❌ No

Max length: 30; autocomplete available.

threshold

Integer

Members with less default score are queued.

❌ No

Min: 0; max: 100.

Examples

/purge add carry-type: dungeons purge-type: inactive threshold: 20
