Dungeon Hub Help

/stats

Description

Displays the bot's uptime and statistics for the current server: member count, total and 30-day money spent, and total and 30-day carry count. Values in parentheses are the totals from the last 30 days.

Examples

Show stats

/stats

The response is titled with the server name and groups all statistics in a single embed.

See Also

  • /leaderboard: ranking views of players.

  • /config: tune server settings that affect bot behavior.
