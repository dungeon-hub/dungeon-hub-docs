/manage-score

Description

Score tracks carry service contributions by service team members. It is normally awarded automatically via the /log command when carries are completed. This command allows administrators to manually adjust scores for edge cases, corrections, or special circumstances.

Score adjustments affect leaderboards and can be viewed with /score.

Permissions

The add and remove sub-commands require the Manage Messages Discord permission. If the SCORE_MANAGEMENT_ROLE server property is configured, users must also have that role to use these commands.

The reset sub-command requires the Administrator Discord permission due to its server-wide impact.

Server administrators can override these default permission requirements using Discord's command permission settings.

Sub-Commands

  • /manage-score add ✏️: Give score to a service team member.

  • /manage-score remove ✏️: Remove score from a service team member.

  • /manage-score reset ✏️: Reset all scores for a given carry type.

See Also

  • /log: Normal way to earn score by logging carries

  • /score: View a user's current score

  • /leaderboard: View score rankings

  • Server Properties: Configure SCORE_MANAGEMENT_ROLE and SCORE_LOGS_CHANNEL
