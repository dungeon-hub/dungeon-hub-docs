# Features

The Dungeon Hub Bot offers a wide range of useful features to help you manage your Discord server. However, because there are so many features, some of them might be a little confusing for new users. \
The following pages will cover the basics of the bot's features and explain how to use them. For more detailed explanations, you can refer to the linked topics on each feature's page.

- [](Carry-and-Score-System.md) explains carry configuration, ticket logging, score, leaderboards, and purges.
- [](Crafts-Transfers-and-Reputation.md) covers CNT requests, claiming, completion, and reputation.
- [](Embed-Management.md) documents the JSON format used to create and edit Discord embeds.
- [](Player-Profiles.md) explains player data, profile selection, and Hypixel status information.
- [](Player-Lookup-and-Safety.md) covers safety checks for Minecraft players and Discord users.
- [](Role-Management.md) explains automatic roles, requirements, groups, and synchronization.
- [](Server-Property.md) lists server-wide bot configuration.
- [](Static-Messages.md) covers persistent bot-managed embeds.
- [](Ticket-System.md) explains ticket panels and the ticket lifecycle.
- [](Verification.md) covers account linking and synchronization.
- [](Warnings.md) explains moderation records and automated punishments.
