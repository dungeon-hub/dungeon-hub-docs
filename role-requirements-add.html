/role requirements add

Description

Creates a requirement for a Discord role. The selected player value is compared with count whenever roles are synchronized. Use extra-data only when required by the selected requirement type.

Arguments

Name

Type

Description

Optional?

role

Role

Role controlled by the requirement.

❌ No

requirement-type

Enumeration

Player or account value to evaluate.

❌ No

comparison

Enumeration

How the value is compared with the count.

❌ No

count

Integer

Value that must be compared against.

❌ No

extra-data

String

Additional value used by certain requirement types.

✅ Yes

Examples

/role requirements add role: @Experienced requirement-type: Skyblock Level comparison: Greater Or Equal count: 200
