Dungeon Hub Help

/status

Description

Shows whether the selected player is online. When available, an online result includes their current game, mode, and map; an offline result includes when they were last seen and the length of their last session.

If ign is omitted in a ticket channel, the command checks the ticket creator. Otherwise, it checks the Minecraft account linked to the command issuer.

Arguments

Name

Type

Description

Optional?

Additional

ign

String

IGN to check instead of the automatically selected linked player.

✅ Yes

Min length: 2

Examples

/status ign: Taubsie
