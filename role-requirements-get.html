/role requirements get

Description

Displays the selected role's requirements in a paginator. Each page includes the requirement ID needed by the edit and delete commands.

Arguments

Name

Type

Description

Optional?

role

Role

Role whose requirements should be displayed.

❌ No

Examples

/role requirements get role: @Experienced
