/manage-score remove ✏️

Arguments

Name

Type

Description

Optional?

Additional

user

User

Member whose score to modify.

❌ No

—

carry-type

Autocompleted String

Identifier of the carry type.

❌ No

Max length: 30

amount

Integer

Score amount to remove.

❌ No

Min: 0, Max: 10000

Examples

/manage-score remove user: @User carry-type: mm amount: 14

Notes

  • When configured, a log is posted to the SCORE_LOGS_CHANNEL.

  • Relevant static leaderboard messages are updated automatically.

  • The carry type must exist and be configured on your server.

  • Score is typically awarded automatically via /log; use this command for manual adjustments only.

  • If the SCORE_MANAGEMENT_ROLE server property is configured, users must have that role in addition to the Manage Messages permission to use this command.
