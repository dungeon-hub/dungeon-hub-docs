/static-message create

Description

Creates a static-message record, posts its initial embed, and returns a link to the posted message. If no channel is provided, the message is posted in the channel where the command was used. Some message types need objects assigned with /static-message assign-object before they can display useful data.

Arguments

Name

Type

Description

Optional?

static-message-type

String

Content generated for the message.

❌ No

channel

Channel

Target text channel. Defaults to the current channel.

✅ Yes

Examples

/static-message create static-message-type: Reputation Leaderboard channel: #announcements

Available Types

  • Score Leaderboard

  • Total Leaderboard

  • Reputation Leaderboard

  • Ticket Panel

  • Price Message
